## NotebookLM / Gemini Notebook 讨论跳转

- 112 天主课程新增 **「NotebookLM 讨论」** 导航和每日讨论区，可以为每周绑定一份私人 NotebookLM 笔记本，也可以为某一天设置专属笔记本。可一键跳转到该笔记本，使用 Google 完整的对话、Studio、思维导图、信息图、测验、音频概览等功能。
- Anthropic 21 天认证备考页面可以绑定一个专属 NotebookLM 笔记本，讨论链接、相关官方资料、每日问题会随所选日期变化。
- 两个页面都提供 **复制讨论提纲** 和 **复制资料链接**；这些动作不会自动导入资料或提交 NotebookLM 对话。Google 回答不会自动同步回来，可手动记录在本网站的 NotebookLM 收获字段。
- **个人笔记本地址不写在公开 GitHub 代码**；链接与笔记仅存当前浏览器的本地存储，并随各自 JSON 备份一起导出。只有使用拥有该私人笔记本访问权限的 Google 账号登录才能打开。
- Google 于 2026-11 发布新的 [Gemini Notebook API 公开预览](https://developers.google.com/notebook/docs) 与 [官方 MCP 入口](https://developers.google.com/notebook/docs/mcp)。当前 API 可操作笔记本与来源，但 [对话检索及 Studio 内容生成尚属未来计划](https://developers.google.com/notebook/docs/roadmap)，所以网页暂用零服务器成本的直接链接，而不声称已打通内容同步。
- Google 官方 Gemini Notebook 入口：https://notebook.google.com/

## 学习内容

**主课程 `index.html`：** 16 周 / 112 天任务，8 大模块，配套资源、费曼学习法、每日反馈、笔记、周复盘、进度和 JSON 导入导出。已将官方认证资料链接补入相关学习日，第 15 周集中复习。

**认证备考 `exam-prep.html`：** 额外 21 天的独立学习支线，按 CCAR-F 官方五领域组织，提供逐日官方材料、实战练习、费曼问题、笔记、进度、复盘和独立 JSON 备份。该学习计划是原创教学辅助内容，不是 Anthropic 官方模拟考试。

## 隐私、备份与 API 限制

- 网站代码和课程公开，**学习记录只存储在当前浏览器本地**，不自动同步手机和电脑，也不会上传到 GitHub。主课程和认证备考使用不同的本地存储与 JSON 备份文件，切换设备时需要分别导出和导入。
- 不要将学生、家长、员工真实敏感资料或 API Key 输入公开学习页面。
- GitHub Pages 是静态托管，不能安全保管 DeepSeek API Key；**在线版 AI 助教暂未启用**。如需启用，必须使用单独的、具备身份认证和密钥保护的服务。
- 正式 Anthropic 认证考试报名可能需要合作伙伴企业邮箱。考试费、资格、考纲与备考权限以官方最新信息为准。
- 本仓库的学习页不提供 EEC 法规合规判断，也不代表已取得 Anthropic 认证。
