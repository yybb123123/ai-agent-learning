1为什么要拆文件？

项目变大后更容易读、改、测试，也更不容易误改 因为 HTML 不能超过 100 行 因为 GitHub 禁止单文件项目

2三个核心文件分别负责什么？

app.py
game.py
templates/index.html
Flask route、读取浏览器请求、把数据交给页面 固定剧情和选择逻辑 显示剧情和按钮

3什么是 route？

@app.route("/") def index(): ...
浏览器访问某个地址时，Flask 应该运行哪个函数 游戏地图中的道路 Git Push 的路线

4request 在这里负责什么？

choice = request.form.get("choice", "start")
读取玩家从网页提交的选择 自动生成 AI 剧情 创建 Git Commit

5render_template() 做什么？

return render_template("index.html", scene=scene)
把 Python 的 scene 数据交给 HTML 显示 调用 AI API 安装 Flask

6import 是什么？

from game import get_scene
让 app.py 使用 game.py 里的函数 从 GitHub 自动下载项目 把 HTML 转成 Python

7哪个文件不应该负责页面长什么样？

game.py templates/index.html

8Issue #2 应该包含哪些验收标准？

Flask app starts successfully Opening story is visible A / B / C work Restart works Game logic is in Python HTML is inside templates/ No AI API is used Add multiplayer
✅ Acceptance Criteria

9正确的运行顺序

浏览器打开 http://127.0.0.1:5000 python3 -m pip install flask（首次需要） 测试 A / B / C / Restart python3 app.py
▶️ Run & Test

10看到红色错误，第一步做什么？

11为什么修复后还要重新测试其他路径？

修改一个地方可能破坏原本正常的功能 因为 Flask 要求重复点击

12Commit 前分别检查什么？
